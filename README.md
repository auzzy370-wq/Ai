# MLBB Strategy Advisor

Real-time draft picking and in-game strategy advisor for **any Mobile Legends: Bang Bang hero** — installable as a PWA on iPhone.

## Live App

**https://auzzy370-wq.github.io/mlbb-advisor/**

## Install on iPhone (Add to Home Screen)

1. Open the link above in **Safari**
2. Tap the **Share** button (square with arrow)
3. Scroll down → tap **Add to Home Screen**
4. Tap **Add**

The app opens fullscreen with no browser chrome — just like a native app.

## Features

- **Draft Advisor** — pick the best hero based on enemy picks, synergies, role coverage, and tier
- **In-Game Advisor** — real-time tip engine for any hero covering laning, jungling, teamfights, and macro
- **35+ heroes** across all roles: Assassin, Mage, Marksman, Fighter, Tank, Support

## Action Button (iPhone 15 Pro / 16 series)

Set the Action Button to open a **Shortcut** that launches this PWA — gives instant access in one press while playing.

## Deployment

This is a fully static site (HTML + CSS + JS only). No server required.
Hosted on **GitHub Pages** — always free, always on.
